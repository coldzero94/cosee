Cosee 개인정보 안내

Cosee는 이 Mac에서 프로세스 이름, 식별자, 앱 경로, CPU 누적 시간과 메모리 footprint를 읽어 앱별 리소스 사용량과 판단 근거를 보여 줍니다. 최근 측정값은 메모리에 보관하고 앱을 종료하면 지웁니다. 분석 정보는 외부로 전송하지 않으며 프로세스 이름과 사용량을 진단 로그에 기록하지 않습니다. 계정, 분석 추적, 클라우드 처리와 자동 업데이트 기능은 없습니다.

설정은 io.cosee.mac 환경설정에, 가져온 사용자 애니메이션은 ~/Library/Application Support/Cosee에 저장합니다. 사용자 지표는 직접 선택한 로컬 JSON 파일에서만 읽습니다.

앱 종료는 사용자가 대상을 선택하고 확인한 경우에 일반 종료를 요청합니다. 대상 앱에서 작업 저장을 요청하거나 종료를 거절할 수 있습니다.

외부 링크는 사용자가 선택했을 때 브라우저로 열립니다. 방문한 웹사이트의 개인정보 정책이 적용됩니다.

앱을 삭제하려면 Cosee 설정에서 로그인 시 실행을 끄고 Cosee를 종료한 뒤 응용 프로그램에서 Cosee.app을 삭제합니다. 환경설정과 가져온 데이터는 별도로 삭제할 수 있습니다.
